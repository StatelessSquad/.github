### 👋 We're a tiny indie studio where **AI agents do the building** and **humans do the taste**.

We make small, bright, *one-more-go* games that ship to **iOS, Android and the web** from a single TypeScript kit.
Every game is fast (60 fps on a throttled phone), kind (no ads, no accounts, no tracking) and plays offline.
Agents write the code, run the tests and open the PRs; a human approves every visual change before anything ships.

> 🗨️ *"If it can be automated, we already did it (probably in a cronjob)."*

## 🏭 The studio machine

<img src="../assets/pipeline.svg" alt="Idea → visual preview → owner approves → agents build → browser tests → PR and CI → ship to iOS, Android and web" width="100%"/>

<table>
<tr>
<td width="33%" valign="top">

#### 🧰 One kit
`@statelesssquad/kit` gives every game a glass HUD shell, scenes, intent-based input, versioned saves, seeded RNG, synth audio, haptics, themes and a parental gate. A new game only writes its **rules, its look and its content**.

</td>
<td width="33%" valign="top">

#### 🔁 One pipeline
verify → browser tests → visual review → PR → CI → merge → publish. Each game gets its store builds via Capacitor and a generated **product page** in its own `*-public` repo.

</td>
<td width="33%" valign="top">

#### 🤖 One way of working
Requirements → visual preview → plan → **a human approves** → build → review again → ship. Agents keep a [daily log](https://statelesssquad.github.io/stateless-squad-daily-progress-blog/) of what they built, learned and merged.

</td>
</tr>
</table>

<details>
<summary><b>💎 What makes a StateLess Squad game</b> (our quality bar, click to open)</summary>

<br/>

| | |
|---|---|
| 👀 **Eye-catching from frame one** | Glass HUD over an aurora backdrop, light *and* dark that both look designed, a hero moment for the store shot |
| 🍬 **Juice on every action** | A synth sound, a haptic tap, a particle burst, a counter that counts up, a spring on whatever you touched |
| ⚡ **Fast** | 60 fps on a phone with the CPU slowed 4×. Nothing janky on the first tap |
| 💚 **Addictive but kind** | One-line goal, visible progress, *one more go* loops. No dark patterns. No ads in kids' games |
| ⏱️ **The first minute** | Playable in under 3 seconds, one obvious button, a success within 10 seconds |
| 📱 **Everywhere** | Readable on a 280px phone and a 13" iPad |
| 🎲 **Deterministic** | Seeded RNG, `?seed=N` replays, `?autoplay=N` self-play for perf runs |

</details>

## 💚 Open source is our other favourite game

<img src="../assets/opensource.svg" alt="We love open source the same as we love gaming" width="100%"/>

We play open source the way we play games: every week there's a new level to try.

<table>
<tr>
<td width="50%" valign="top">

#### 🧪 We try new ideas, in the open
New engines, new flows, new agent workflows. If it looks fun, we prototype it, measure it, and keep what wins. Our experiments are public, and so are our notes.

</td>
<td width="50%" valign="top">

#### ⬆️ We live on the latest stack
Exact pinned versions, Dependabot on every repo, and upgrades soon after they ship. When a better tool lands, we try it straight away.

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🤝 We give back upstream
We build on open source, so we contribute back: bug reports, fixes and PRs to the tools we use, plus our own templates and patterns for anyone to fork.

</td>
<td width="50%" valign="top">

#### 🔁 We change things, on purpose
New flows get tried, reviewed and shipped, not parked in a backlog. Fail fast, learn faster, then respawn with a better build.

</td>
</tr>
</table>

> 🎮 *Open source is a co-op game with no final boss. Patch notes every day, and everyone's invited to the party.*
