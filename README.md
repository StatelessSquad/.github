## 🧠 About Us

We are StatelessSquad, an R&D-driven squad of cloud-native engineers, AI tooling enthusiasts, and automation obsessives. We specialize in building resilient, stateless systems on Kubernetes, leveraging Terraform for IaC, and weaving in LLM-powered workflows via Hermes. Our days are spent prototyping in Jupyter, pushing to GitHub Actions, and observing with OpenTelemetry—always with an eye toward production-grade reliability and developer experience.

> 🗨️ *"If it can be automated, we already did it (probably in a cronjob)."*
